# Palworld Trainer — feature reference

A task-oriented Palworld trainer workspace: player settings first, companion groups next, and inventory categories as the final reference area.

| Section | Description |
|---|---|
| Player settings | Character-related parameters and the settings associated with the selected category. |
| Companion groups | A dedicated section for companion groups and the configuration details associated with that area. |
| Inventory categories | Inventory and resource categories organized alongside their related values and notes. |

The project page follows the same section structure.
